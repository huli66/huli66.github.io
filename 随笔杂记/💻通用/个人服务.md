## 一、系统选择与烧录

### 推荐系统

**Raspberry Pi OS Lite (64-bit)**（基于 Debian Bookworm）

- 无桌面环境，省资源（省出来的内存给服务用）
- 官方支持最好，社区资源丰富
- 64 位对 Java 系服务（Kafka）更友好

### 烧录步骤

1. 下载 [Raspberry Pi Imager](https://www.raspberrypi.com/software/)
2. 选择 **Raspberry Pi OS Lite (64-bit)**
3. 点击右下角齿轮图标，提前配置：
    - Hostname：`homepi`（或你喜欢的名字）
    - 开启 SSH，选择密钥登录（更安全）
    - 配置 WiFi（但强烈建议用**网线**，稳定性差异显著）
    - 设置用户名和密码
4. 写入 SD 卡

> ⚠️ **强烈建议**：用 USB 外接 SSD 来存放数据，SD 卡只装系统。长期高频读写会损坏 SD 卡。

## 二、系统初始化

SSH 进入树莓派后，按顺序执行：

### 1. 更新系统

```bash
sudo apt update && sudo apt full-upgrade -y
sudo reboot
```

### 2. 换国内镜像源（可选，网络不佳时使用）

```bash
# 中科大源（Debian Bookworm）
sudo sed -i 's/deb.debian.org/mirrors.ustc.edu.cn/g' /etc/apt/sources.list
sudo apt update
```

### 3. 安装基础工具

```bash
sudo apt install -y git curl wget vim htop net-tools ufw fail2ban
```

### 4. 配置固定局域网 IP

编辑 `/etc/dhcpcd.conf`，在末尾添加：

```
interface eth0
static ip_address=192.168.1.100/24
static routers=192.168.1.1
static domain_name_servers=192.168.1.1 8.8.8.8
```

```bash
sudo systemctl restart dhcpcd
```

### 5. 配置 Swap（保险起见）

```bash
sudo dphys-swapfile swapoff
sudo nano /etc/dphys-swapfile
# 修改：CONF_SWAPSIZE=2048
sudo dphys-swapfile setup
sudo dphys-swapfile swapon
```

### 6. 基础安全配置

```bash
# 启用防火墙
sudo ufw allow ssh
sudo ufw allow 80
sudo ufw allow 443
sudo ufw enable

# 禁用密码登录（确保已配置 SSH 密钥后再做）
sudo sed -i 's/#PasswordAuthentication yes/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo systemctl restart ssh
```

### 7. 设置时区

```bash
sudo timedatectl set-timezone Asia/Shanghai
```

## 三、Docker + Docker Compose

**所有服务均通过 Docker 管理**，优势：

- 各服务完全隔离，互不干扰
- 版本管理方便，一行命令升降级
- 开机自动重启，免维护
- 备份迁移极其方便

### 安装 Docker

```bash
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
newgrp docker   # 或重新登录使组生效
```

### 验证安装

```bash
docker version
docker compose version
```

### 创建工作目录

```bash
mkdir -p ~/services/data/{mysql,redis,rabbitmq,kafka,nginx/{conf.d,html}}
mkdir -p ~/services/monitoring
cd ~/services
```

## 四、核心中间件部署

### MySQL 8.0

- 端口：`3306`
- 数据持久化到 `./data/mysql`
- 支持远程连接（`MYSQL_ROOT_HOST: '%'`）

### Redis 7

- 端口：`6379`
- 开启 AOF 持久化（`appendonly yes`）
- 设置密码保护

### RabbitMQ 3

- 端口：`5672`（AMQP）、`15672`（Web 管理界面）
- 自带管理界面，可视化查看队列状态

### Kafka（含 Zookeeper）

- 端口：`9092`
- 注意：需将 `KAFKA_ADVERTISED_LISTENERS` 中的 IP 改为你的局域网 IP
- Confluent 镜像支持 ARM64，适合树莓派

> ⚠️ Kafka 比较吃内存（约 512MB+），学习初期可以只在需要时启动：`docker compose up -d kafka`

### Nginx

- 端口：`80`、`443`
- 配置文件挂载到 `./nginx/conf.d`
- 可用于反向代理所有服务，统一从 80/443 访问

## 五、性能监控与网络测速

### 监控方案：Prometheus + Grafana + Node Exporter

这是目前最成熟的开源监控技术栈：

- **Node Exporter**：采集树莓派硬件指标（CPU、内存、磁盘、温度）
- **Prometheus**：时序数据库，定期抓取指标
- **Grafana**：可视化仪表盘，有大量现成模板

访问地址：

- Prometheus：`http://树莓派IP:9090`
- Grafana：`http://树莓派IP:3000`（默认账号 `admin/admin`）

> 在 Grafana 中导入模板 ID **1860**（Node Exporter Full），即可获得漂亮的完整系统监控面板。

### 网络测速：Speedtest Tracker

- 端口：`8765`
- 定时自动跑 Speedtest，记录历史数据并展示趋势图
- 适合监控家庭宽带稳定性

访问：`http://树莓派IP:8765`

### Prometheus 配置文件

创建 `~/services/prometheus/prometheus.yml`：

```yaml
global:
  scrape_interval: 15s

scrape_configs:
  - job_name: 'node'
    static_configs:
      - targets: ['node-exporter:9100']

  - job_name: 'prometheus'
    static_configs:
      - targets: ['localhost:9090']
```

## 七、完整 docker-compose.yml

将以下内容保存为 `~/services/docker-compose.yml`，**将所有 `YOUR_PASSWORD` 和 `192.168.1.100` 替换为实际值**：

```yaml
version: '3.8'

networks:
  pi-net:
    driver: bridge

services:

  # ========== 核心中间件 ==========

  mysql:
    image: mysql:8.0
    container_name: mysql
    restart: always
    networks: [pi-net]
    environment:
      MYSQL_ROOT_PASSWORD: YOUR_PASSWORD
      MYSQL_ROOT_HOST: '%'
    ports:
      - "3306:3306"
    volumes:
      - ./data/mysql:/var/lib/mysql
    command: --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci

  redis:
    image: redis:7-alpine
    container_name: redis
    restart: always
    networks: [pi-net]
    ports:
      - "6379:6379"
    volumes:
      - ./data/redis:/data
    command: redis-server --requirepass YOUR_PASSWORD --appendonly yes

  rabbitmq:
    image: rabbitmq:3-management
    container_name: rabbitmq
    restart: always
    networks: [pi-net]
    ports:
      - "5672:5672"
      - "15672:15672"
    environment:
      RABBITMQ_DEFAULT_USER: admin
      RABBITMQ_DEFAULT_PASS: YOUR_PASSWORD
    volumes:
      - ./data/rabbitmq:/var/lib/rabbitmq

  zookeeper:
    image: confluentinc/cp-zookeeper:7.5.0
    container_name: zookeeper
    restart: always
    networks: [pi-net]
    environment:
      ZOOKEEPER_CLIENT_PORT: 2181
      ZOOKEEPER_TICK_TIME: 2000

  kafka:
    image: confluentinc/cp-kafka:7.5.0
    container_name: kafka
    restart: always
    networks: [pi-net]
    depends_on:
      - zookeeper
    ports:
      - "9092:9092"
    environment:
      KAFKA_BROKER_ID: 1
      KAFKA_ZOOKEEPER_CONNECT: zookeeper:2181
      KAFKA_ADVERTISED_LISTENERS: PLAINTEXT://192.168.1.100:9092
      KAFKA_OFFSETS_TOPIC_REPLICATION_FACTOR: 1
      KAFKA_LOG_RETENTION_HOURS: 24
      KAFKA_HEAP_OPTS: "-Xmx512m -Xms256m"  # 限制内存，适合树莓派

  nginx:
    image: nginx:alpine
    container_name: nginx
    restart: always
    networks: [pi-net]
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx/conf.d:/etc/nginx/conf.d
      - ./nginx/html:/usr/share/nginx/html

  # ========== 监控与测速 ==========

  node-exporter:
    image: prom/node-exporter:latest
    container_name: node-exporter
    restart: always
    networks: [pi-net]
    volumes:
      - /proc:/host/proc:ro
      - /sys:/host/sys:ro
      - /:/rootfs:ro
    command:
      - '--path.procfs=/host/proc'
      - '--path.sysfs=/host/sys'
      - '--collector.filesystem.ignored-mount-points=^/(sys|proc|dev|host|etc)($$|/)'
    expose:
      - 9100

  prometheus:
    image: prom/prometheus:latest
    container_name: prometheus
    restart: always
    networks: [pi-net]
    ports:
      - "9090:9090"
    volumes:
      - ./prometheus/prometheus.yml:/etc/prometheus/prometheus.yml
      - ./data/prometheus:/prometheus
    command:
      - '--config.file=/etc/prometheus/prometheus.yml'
      - '--storage.tsdb.retention.time=15d'  # 保留15天数据

  grafana:
    image: grafana/grafana:latest
    container_name: grafana
    restart: always
    networks: [pi-net]
    ports:
      - "3000:3000"
    volumes:
      - ./data/grafana:/var/lib/grafana
    environment:
      GF_SECURITY_ADMIN_PASSWORD: YOUR_PASSWORD

  speedtest-tracker:
    image: lscr.io/linuxserver/speedtest-tracker:latest
    container_name: speedtest-tracker
    restart: always
    networks: [pi-net]
    ports:
      - "8765:80"
    environment:
      - PUID=1000
      - PGID=1000
      - APP_KEY=base64:YOUR_RANDOM_32CHAR_KEY  # 生成：openssl rand -base64 32
      - DB_CONNECTION=sqlite
    volumes:
      - ./data/speedtest:/config

  # ========== 运维工具 ==========

  portainer:
    image: portainer/portainer-ce:latest
    container_name: portainer
    restart: always
    networks: [pi-net]
    ports:
      - "9000:9000"
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - ./data/portainer:/data

  uptime-kuma:
    image: louislam/uptime-kuma:latest
    container_name: uptime-kuma
    restart: always
    networks: [pi-net]
    ports:
      - "3002:3001"
    volumes:
      - ./data/uptime-kuma:/app/data

  adminer:
    image: adminer:latest
    container_name: adminer
    restart: always
    networks: [pi-net]
    ports:
      - "8088:8080"

  # ========== 开发工具（按需启用） ==========

  gitea:
    image: gitea/gitea:latest
    container_name: gitea
    restart: always
    networks: [pi-net]
    ports:
      - "3001:3000"
      - "2222:22"
    volumes:
      - ./data/gitea:/data
    environment:
      - USER_UID=1000
      - USER_GID=1000

  code-server:
    image: lscr.io/linuxserver/code-server:latest
    container_name: code-server
    restart: unless-stopped  # 不需要时手动启动
    networks: [pi-net]
    ports:
      - "8080:8443"
    environment:
      - PUID=1000
      - PGID=1000
      - PASSWORD=YOUR_PASSWORD
      - SUDO_PASSWORD=YOUR_PASSWORD
    volumes:
      - ./data/code-server:/config
      - ~/projects:/home/coder/projects  # 挂载项目目录
```

## 八、远程访问方案

### 方案 A：Tailscale（首选，日常访问）

最适合个人使用：免费、零配置、端对端加密、不需要公网 IP。

```bash
# 安装
curl -fsSL https://tailscale.com/install.sh | sh

# 启动并认证
sudo tailscale up

# 查看分配到的 Tailscale IP
tailscale ip
```

手机、电脑也安装 Tailscale 并登录同一账号，即可在任何地方用 Tailscale IP 直接访问树莓派上的所有服务。

**示例**：在公司电脑访问家里树莓派的 Grafana：`http://100.x.x.x:3000`

### 方案 B：Cloudflare Tunnel（对外暴露 Web 服务）

适合将某个 Web 应用通过自定义域名对外展示（例如给别人看你的项目），提供 HTTPS，不暴露本机 IP。

```bash
# 安装 cloudflared
wget https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-arm64.deb
sudo dpkg -i cloudflared-linux-arm64.deb

# 登录 Cloudflare（需要有域名）
cloudflared tunnel login

# 创建 Tunnel
cloudflared tunnel create homepi

# 配置 ~/.cloudflared/config.yml
# 将 home.yourdomain.com 指向本地 80 端口
cloudflared tunnel run homepi
```

### 两种方案对比

|对比项|Tailscale|Cloudflare Tunnel|
|---|---|---|
|使用场景|个人访问所有服务|对外公开 Web 应用|
|需要域名|否|是|
|访问速度|快（P2P 直连）|中（经 CF 节点中转）|
|需要公网 IP|否|否|
|费用|免费（个人版）|免费|

> ✅ **推荐同时使用两者**：Tailscale 用于日常调试访问，Cloudflare Tunnel 用于对外展示项目。

## 九、稳定性与维护

### 散热

树莓派长期满载运行必须散热，否则会降频。推荐：

- 铝合金外壳（被动散热，安静）
- 或加装小风扇（主动散热，更保险）

```bash
# 查看当前温度（应低于 70°C，超过 80°C 会降频）
vcgencmd measure_temp

# 查看是否降频
vcgencmd get_throttled
# 返回 0x0 表示正常，其他值表示有降频发生
```

### 存储策略

```
推荐布局：
SD 卡（16GB+）  → 系统文件 /
USB SSD（128GB+）→ /home/pi/services/data（所有容器数据）
```

挂载 USB SSD：

```bash
# 查看磁盘
lsblk

# 格式化（如果是新盘）
sudo mkfs.ext4 /dev/sda1

# 获取 UUID
sudo blkid /dev/sda1

# 开机自动挂载（编辑 /etc/fstab）
UUID=你的UUID /mnt/ssd ext4 defaults,noatime 0 2

# 将数据目录迁移到 SSD
sudo mount -a
mv ~/services/data /mnt/ssd/
ln -s /mnt/ssd/data ~/services/data
```

### 自动备份

创建 `~/backup.sh`：

```bash
#!/bin/bash
BACKUP_DIR="/mnt/ssd/backups"
DATE=$(date +%Y%m%d_%H%M%S)

# 停止服务，确保数据一致性
docker compose -f ~/services/docker-compose.yml stop mysql redis

# 压缩备份
tar -czf "$BACKUP_DIR/services_$DATE.tar.gz" ~/services/data

# 重启服务
docker compose -f ~/services/docker-compose.yml start mysql redis

# 只保留最近 7 天备份
find $BACKUP_DIR -name "*.tar.gz" -mtime +7 -delete

echo "备份完成: services_$DATE.tar.gz"
```

```bash
chmod +x ~/backup.sh

# 添加每天凌晨 3 点自动备份
crontab -e
# 添加：0 3 * * * /home/pi/backup.sh >> /home/pi/backup.log 2>&1
```

### 查看资源使用

```bash
# 实时查看所有容器资源占用
docker stats

# 查看内存使用
free -h

# 查看磁盘使用
df -h
```

### 常用 Docker 命令

```bash
# 启动所有服务
docker compose up -d

# 停止所有服务
docker compose down

# 单独启动某个服务
docker compose up -d kafka

# 查看日志
docker compose logs -f mysql

# 更新镜像
docker compose pull && docker compose up -d

# 清理无用数据（定期执行）
docker system prune -f
```

## 十、学习路径建议

### 阶段一：基础环境（第 1 周）

完成系统配置 → Docker 安装 → 启动 MySQL + Redis + Nginx → 用 Portainer 查看容器状态 → 配置 Tailscale 远程访问

### 阶段二：全栈开发基础（第 2-4 周）

- Nginx 配置静态文件托管，部署前端项目
- 用 Node.js 或 Python 连接 MySQL，写简单的 CRUD API
- Nginx 反向代理，将 API 和前端统一到同一端口
- Redis 实现接口缓存、Session 存储

### 阶段三：消息队列（第 5-6 周）

- RabbitMQ：实现异步任务处理（邮件发送、图片处理等场景）
- 理解 Exchange、Queue、Binding 的关系
- Kafka：实现日志收集或事件流处理

### 阶段四：监控与运维（持续）

- Grafana 配置业务指标监控
- Uptime Kuma 监控服务可用性
- 学习 Docker 网络、Volume、多服务编排
