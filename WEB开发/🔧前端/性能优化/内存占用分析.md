
为什么鼠标悬浮在浏览器 tab 上显示内存占用高达几个 G，而 DevTools 中只能看到 200 MB 左右？

一个浏览器页面占用的所有内存 应该在哪里查看？怎么优化？

## 内存占用分布

	 tab 显示的数字是整个渲染进程的 RSS（常驻内存集），包含下述的所有部分

### JS Heap
js 堆栈内存， DevTools 中可以看到（Memory 面板采样的也只有这部分内存）
由 V8 引擎管理，会有一个初始大小大概在 40 MB，一般页面视情况在 1～200 MB 属于正常情况
用于存储 代码/对象/字符串/数组/闭包
通过 GC 进行回收，通常的内存泄露说的就是这部分内容
代码量为什么占那么大内容，因为要跑在 V8 上所以存在内存里？

### GPU 内存
纹理/Canvas/WebGL 缓冲区/图层合成/视频帧解码/CSS 动画缓存

不包含在 DevTools 中，最常见的内容是 **图层合成** 部分，可以在 DevTools 的 Layers 中看到具体分层信息，图层数量和每个图层的物理像素大小决定内存占用量，图层渲染次数和频率影响 CPU 占用率
