

## 换肤动效

### js 改变换肤可视化效果
```js
const changeTheme = () => {
	document.documentElement.setAttribute('data-theme', 'light');
}

const handelClick = (item: IDistributionItem) => {
	if (!document.startViewTransition) {
		// 浏览器不支持 view-transition 时，直接打开弹窗
		changeTheme();
	}
	// 浏览器支持 view-transition 时，使用 view-transition 打开弹窗
	document.startViewTransition(() => {
		changeTheme()
	});
};
```

}

// 整个变换发生的过渡函数
::view-transition-group(root) {
animation-timing-function: var(--expo-out);
}

// 新页面出现的动效和时间

}

}

// 单独控制某个主题下的动效
.dark::view-transition-old(root) {

}
