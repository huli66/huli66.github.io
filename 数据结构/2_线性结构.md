# 线性结构

## 线性表

- 多项式存储
  - 数组表示所有项：idx 为 指数，value 为系数
  - 二元数组表示非零项
  - 链表结构存储非零项：系数，指数，指针域
- **线性表**：同类型数据元素构成的有序序列的线性结构
  - 长度：元素个数
  - 空表
  - 表头表尾
- 用数组的连续空间来存放线性表的各元素
- 广义表、多重链表

## 堆栈

- 中缀表达式：运算符位于两个运算数之间，a + b * c - d  / e
- 后缀表达式：运算符位于两个运算数之后，a b c * + d e / -
  - 从左往右扫描，逐个处理运算数和运算符号
  - 全部一个一个放入栈中，遇到运算符号则取最上面的两个进行计算，将结果入栈
- 堆栈（Stack）：具有一定操作约束的线性表
  - 只在栈顶（Top）做插入、删除
  - 插入：入栈（push）
  - 删除：出栈（pop）
  - 后入先出：Last In First Out，LIFO
- 操作
  - 创建指定长度的栈
  - push / pop
  - ifEmpty
- 栈的顺序存储结构通常由一个一维数组和一个记录栈顶的元素位置的变量组成
- 也可以用单链表来实现，用链表的头来作为栈顶 Top
- **中缀表达式转换为后缀表达式：用堆栈存符号**
  - 运算数：直接输出
  - 左括号：压入栈
  - 右括号：将栈顶运算符弹出并输出，直到遇到左括号（出栈，不输出）
  - 运算符
    - 若优先级大于栈顶运算符时，压入栈
    - 若优先级小于等于栈顶运算符时，将栈顶运算符弹出并输出，再比较新的栈顶，直到该运算符优先级大于栈顶运算符为止，然后压入栈
  - 若各对象处理完，则把栈中存留的运算符一并输出
- 堆栈的其他用处
  - 函数调用和递归实现
  - 深度优先搜索
  - 回溯算法
  - 。。。

## 队列

- 定义：具有一定操作约束的线性表（普通线性表两边都可以出入，栈也是受约束）
  - 一端插入，另一端删除
  - FIFO
- 顺序存储实现
  - 一维数组 + 一个队头位置 + 一个队尾位置
  - 链表：表尾做添加（队头），表头做删除（队尾）

## 一元多项式的加法和乘法

- 加法
  - 每项相加，同类项合并
- 乘法
  - 每一项跟另外一项的合并，同类项合并
