# 树

***树**：n（n>=0）个节点构成的有限集合*

空树

根 和 互不相交的子树

  - 叶结点 Leaf

  - 子结点 Child

  - 祖先结点 Ancestor
  - 子孙结点 Descendant
  - 结点的层次 Level：**根结点为 1**
  - 树的深度：树的所有结点的最大深度

  - 一个结点有 FirstChild 和 NextSibling 两部分
  - 旋转45度就是二叉树了，Left 和 Right

## 二叉树

定义：一个有穷的结点集合

这个集合可以是空，也可以是由根结点和左子树TL及右子树TR组成

- 二叉树的五种基本形态

  - 空树

  - 根结点

  - 根结点和左子树
  - 根结点和右子树
  - 根结点和左右两个子树

- 斜二叉树

- **完美二叉树（满二叉树）：二叉树的每一层都是满的**

- **完全二叉树 Complete Binary Tree：结点位置与完美二叉树一致，但是不满的**

- 二叉树的性质

  - 第 i 层有 2^(i - 1) 个结点
  - k 层树最多有 2^k - 1个结点
  - **度为 2 的结点数为 n，则叶结点的数为 n + 1**
  -  结点总数 = 度为2的结点 + 度为1的结点 + 叶结点

- 操作集

  - 判断是否非空
  - 遍历：按照顺序访问每个结点
  - 创建一个二叉树

- 遍历（每个结点都有三次机会碰到，第几次返回分为先中后序）

  - 先序遍历
  - 中序遍历
  - 后序遍历
  - 层次遍历

### 二叉树的存储结构

- 顺序存储
  - 完全二叉树按照从上到下从左往右存入数组
  - 父结点为 [i / 2]，左孩子为 2i，右孩子为 2i+ 1
  - 一般二叉树也可以这样存储，但是要补满，会造成空间浪费
- 链表存储
  - Left
  - Data
  - Right

## 二叉树的遍历

- 递归实现

- ```js
  // 结点
  function Node(data, left, right) {
  	this.left = left;
    this.right = right;
    this.data = data;
  }
  // 先序遍历
  function First (root) {
    if (root) {
      console.log(root.data);
      First(root.left);
      First(root.right);
    }
  }
  // 中序
  function Middle (root) {
    if (root) {
      Middle(root.left);
      console.log(root.data);
      Middle(root.right);
    }
  }
  // 后序
  function Last (root) {
    if (root) {
      Last(root.left);
      Last(root.right);
      console.log(root.data);
    }
  }
  ```

- 非递归方法实现（递归的根本原理是堆栈，这里尝试直接使用堆栈）

- ```js
  function (root) {
    let stack = [];
    let res = [];
    while (root || stack.length > 0) {
      while (root) {
        // 第一次访问这个结点，先序遍历在这里输出
        stack.push(root);
        // res.push(root.val);
        root = root.right;
      }
      // 第二次访问这个结点，中序遍历在这里输出
      root = stack.pop();
      // res.push(root.val);
      root = root.right;
    }
  }
  ```

- 层序遍历

  - 创建一个空队列，根结点入队
  - 循环：把一个结点出队，读取，然后入队其左、右子结点

- 二叉树遍历的核心问题：二维结构的线性化
  - 从结点访问其左、右子树
- 利用后序遍历（递归）求树的深度
- 没有中序遍历序列无法还原整个树
- 树的同构
  - 可以通过若干次左右子树互换转换则是同构树
  - 二叉树的表示
    - 链表：每个结点有左右子树（可以为空）
    - 数组：视为完全二叉树，缺少的结点为空
    - 结构数组表示二叉树：**静态链表**
      - 数组的每一项是一个对象，对象有三项，左儿子索引（空为 -1），右儿子索引，数据
  - 判断是否同构
    - 建二叉树：把数组表示的数组转换成链表表示，返回 root
    - 判断同构：root，空

## 二叉搜索树

- **二叉搜索树（BST，Binary Search Tree）即二叉排序树、二叉查找树**
  - 非空左子树的所有结点值都小于根结点值
  - 非空右子树的所有结点值都大于根结点值
  - 左子树和右子树都是二叉搜索树
  - 操作：查找、插入、删除、最小值位置、最大值位置
- **尾递归都可以用循环实现**
- 删除结点：如果只有左子树（或右子树）则直接街上，否则接左子树最大值或右子树最小值

## 平衡二叉树

查找效率由树的深度决定，平均查找长度 ASL

AVL 树，平衡二叉树：空树或者任一结点左右子树高度差的绝对值不超过1

## 堆

- 优先队列：特殊的队列，取出元素的顺序是依照元素的优先权大小，而不是入队顺序
- 数组、链表、有序数组、有序链表
- **堆：用完全二叉树来存储**
  - 结构性：用数组表示的完全二叉树，0放哨兵，1开始存根结点
  - 有序性：任一结点的关键字是其子树所有结点的最大值（最小值
    - 最大堆 MaxHeap，大顶堆
    - 最小堆 MinHeap，小顶堆
- **插入**
  - 放到当前完全二叉树最后一位
  - 循环，与父结点比较，若大于父结点，交换，直到小于父结点
- **删除（取出最大值，即堆顶）**
  - 取出根结点的值，将最后一个结点移到根结点位置
  - 循环，找出较大的孩子，交换，直到没有左儿子（idx * 2 > size）
- 建立
  - 通过插入操作，一个一个相继插入，时间代价最大为 O(N log N)
  - 在线性时间复杂度下建立最大堆
    - 1.将 N 个元素按输入顺序存入，先满足完全二叉树的结构特性
    - 2.调整各结点位置，满足最大堆特性

## 哈夫曼树和哈夫曼结构

哈夫曼树，最优二叉树：结点出现频率（权值）和路径的乘积和最小？

带权路径长度值：WPL

- **构造：每次把权值最小的两棵二叉树合并**
  - 合并得到的二叉树权值为两个子树权值和
- 特点
  - 没有度为 1 度结点
  - n 个叶子结点的哈夫曼树共有 2n - 1 个结点
    - 叶结点总数 - 1 = 有两个儿子的结点总数
    - 没有只有一个儿子的结点
  - 哈夫曼树的任意非叶子结点的左右子树交换后仍是哈夫曼树
  - 同一组叶子结点形成的不同构哈夫曼树权值（WPL）一样
- 哈夫曼编码
  - 如何避免二义性
    - 前缀码：任何字符的编码都不是另一字符编码的前缀
    - 用二叉树进行编码：左右分支为 0、1，字符只在叶结点上，哈夫曼树最优
