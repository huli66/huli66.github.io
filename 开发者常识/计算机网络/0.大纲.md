## 专业词汇及缩写

### 第一章
- host 主机：端系统也称主机，主机上面运行应用程序
- end system 端系统：与因特网相连的计算机或其它设备（PC、服务器、移动计算机等）
- communication link 通信链路
- packet switch 分组交换机
- transmission rate 传输速率，以比特/秒（bit/s 或者bps ）度量
- packet 分组：端系统向另一个端系统发送数据，发送端需要将数据分段，并给每段加上首部字节，这样形成的信息叫分组
- router 路由器
- link-layer switch 链路层交换机
- ISP Internet Service Provider 因特网服务提供商
- protocol 协议
- TCP transmission Control Protocol 传输控制协议
- IP Internet Protocol 网际协议
- IETF Internet Engineering Task Force 因特网工程任务组
- RFC Request For Comment 请求评论
- socket interface 套接字接口
- edge router 边缘路由器
- DSL Digital Subscriber Line 数字用户线
- LTE Long-Term Evolution 长期演进
- UTP Unshielded Twisted Pair无屏蔽双绞线
- LEO Low-Earth Orbiting 近地轨道
- FDM Frequency-Division Multiplexing 频分复用
- TDM Time-Division Multiplexing 时分复用
- band-width 带宽
