### 烧录系统

[参考](https://www.youtube.com/watch?v=qRSgM8_2XUs)

- 下载官网提供的 64 位系统镜像，可以选择带 desktop 的，烧录到 TF 卡内，完成后被命名为 bootfs
- 打开默认的 ssh 连接功能：在 bootfs 下创建一个 ssh 文件
- 修改默认用户名和密码，新版系统没有初始化用户名密码，新建 `userconf.txt` 文件
- 打开默认的 WIFI 连接，或者跳过这步使用网线连接
- wifi 找到树莓派的局域网 ip，通过 ssh 连接，修改pi用户密码 `sudo passwd pi`
- `sudo raspi-config` ，修改时区和允许使用所有空间，重启再次连接
- 换国内源
	- 备份原来的两个文件
		- `sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak`
		- `sudo cp /etc/apt/sources.list.d/raspi.list /etc/apt/sources.list.d/raspi.list.bak`
	- 修改文件，*bookworm是树莓派的一个版本名，书虫*
		- `sudo nano /etc/apt/sources.list`
		- 注释或者删除原有内容，注释方便恢复
		- 换上这三行内容，`ctrl o` 保存，`ctrl x` 退出，（能用 vim 吗）
			- `deb https://mirrors.tuna.tsinghua.edu.cn/debian bookworm main contrib non-free-firmware`
			- `deb https://mirrors.tuna.tsinghua.edu.cn/debian-security bookworm-security main contrib non-free-firmware`
			- `deb https://mirrors.tuna.tsinghua.edu.cn/debian bookworm-updates main contrib non-free-firmware`
		- `sudo nano /etc/apt/sources.list.d/raspi.list`
			- `deb https://mirrors.tuna.tsinghua.edu.cn/raspberrypi bookworm main`
	- 升级源 `sudo apt-get update;sudo apt-get upgrade;sudo apt-get dist-upgrade;sudo rpi-update`
		- 等待，全部选 yes

- 中文输入法 [参考](https://raspberrypi.club/350.html)
	- `apt install -y fcitx fcitx-googlepinyin`
	- 重启后 preferences -- fcitx 中配置

### 下载 openwrt 系统镜像

immortalwrt 作为旁路由，从官网下载 immortalwrt 压缩包

[下载地址](https://downloads.staging.immortalwrt.org/releases/21.02.7/targets/armvirt/64/)
```bash
# 下载 immortalwrt
wget https://downloads.staging.immortalwrt.org/releases/21.02.7/targets/armvirt/64/immortalwrt-21.02.7-armvirt-64-default-rootfs.tar.gz

# openwrt
wget https://downloads.openwrt.org/releases/21.02.7/targets/armvirt/64/openwrt-21.02.7-armvirt-64-default-rootfs.tar.gz

# 解压为 tar 格式，immortalwrt-21.02.7-armvirt-64-default-rootfs.tar
gunzip immortalwrt-21.02.7-armvirt-64-default-rootfs.tar.gz
# 导入为镜像
sudo docker import immortalwrt-21.02.7-armvirt-64-default-rootfs.tar immortalwrt

# 开启网卡混杂模式，这样开启本次重启之前
ip link set eth0 promisc on
# 设置开机自动开启混杂模式，然后添加上一条命令
nono /etc/rc.local

# 创建网络命名为 openwrt
docker network create -d macvlan --subnet=192.168.3.0/24 --gateway=192.168.3.1 -o parent=eth0 openwrt
# 查看
docker network ls

# 创建容器
docker run --name openwrt -d --network openwrt --privileged openwrt /sbin/init
# 进入容器
docker exec -it openwrt /bin/sh
# 修改默认地址，访问 openwrt 主页的浏览器地址，lan 的 ipaddr 设置为 192.168.3.88
vi /etc/config/network
# 重启容器网络
service network restart
exit

# 设置自启动
docker update --restart=always openwrt
```

进入刚刚设置的浏览器地址 192.168.3.88 用户名 root 密码 password

必须网线连接，wifi 连接不行

设置旁路由，[参考视频 12:10 之后](https://www.youtube.com/watch?v=IwZihudWWA4)

- 树莓派刷 Linux 系统并安装 docker

- docker 跑 HomeAssistant 镜像

- 跑 clash 或者 openwrt 镜像

### 第一步：刷系统和docker

1. 系统镜像选择一个64位的 Debian 系统 (地址) [地址](https://github.com/openfans-community-offical/Debian-Pi-Aarch64/blob/master/README_zh.md) ，原因是这个镜像提供了默认的 docker 容器服务和web界面，并且按照文档介绍，也是一款非常适合的系统，（建议下载使用之前线浏览一遍前面连接的README文件），下载“无桌面基础系统加强版”这个镜像到本地，版本直接选择最新版，可以使用迅雷云盘转存下载（比百度云盘快得多）

2. 选择使用官方的镜像烧录工具 raspberry pi imager，选择系统滚动到最下面选择custom，然后选择自己下载的镜像地址，不需要更改默认设置，这个过程大概需要10分钟，根据个人设备情况而定。烧录完成后如果开发版是支持WIFI的话，可以修改配置文件 `/boot/wpa_supplicant.conf` (参考)[https://github.com/openfans-community-offical/Debian-Pi-Aarch64/blob/master/README_zh.md#3-5%E6%97%A0%E7%BA%BF%E9%85%8D%E7%BD%AE%E8%AF%B4%E6%98%8E] ，先把无线网络相关信息配置好，省的连网线

3. 插上电源就可以使用了，第一次启动需要进行初始化，会重启设备三次，等待三分钟左右，然后就可以在路由器管理的app或者web界面中找到树莓派的ip，在浏览器上打开 Web 可视化管理界面，登录地址 https://你树莓派的IP地址:9090 ，默认账户：pi，默认密码：raspberry，进去后可以选择终端，`docker version` 查看，如下
